# POST questionnaire — full item wording (English)

Referenced from the article "Practice over Generation: AI-Authored
Resources Rank Lowest in Engineering and Computer Science Education"
(IEEE Transactions on Education submission), Data Availability
Statement. This document lists the exact wording of every item across
the questionnaire's five blocks.

All items use a five-point Likert scale (1 = strongly disagree; 2 =
disagree; 3 = neutral; 4 = agree; 5 = strongly agree), except Q09
(forced choice of four resources) and Q14/Q15 (open-ended), indicated
as such below. Block 1 (demographics, not analysed in the article) is
omitted.

## Block 2 — Self-perceived learning and performance (Q01–Q07)

Q01–Q06 have a matched PRE-course item; Q07 is the block's global
rating.

| Item | Label | Statement |
|---|---|---|
| Q01 | Programming ability | I can currently solve basic computational problems using programming. |
| Q02 | Academic relevance | The knowledge developed in this course has helped my academic performance in other courses. |
| Q03 | Professional relevance | The knowledge developed in this course will be useful for my professional career. |
| Q04 | Mathematical foundations | I currently consider my background in Linear Algebra and Calculus (concepts used in DIP) to be very good. |
| Q05 | Library autonomy | I currently feel I have good autonomy to use data/image processing libraries (e.g., OpenCV, NumPy, Matplotlib, `morph.py`). |
| Q06 | AI feedback | I currently consider AI-generated automated code feedback useful. |
| Q07 | *(Block global)* | Overall, I consider that my theoretical and practical knowledge in the field has evolved significantly throughout this course. |

## Block 3 — Teaching resources (Q08_01–Q08_11, Q09, Q10)

Q08_01–Q08_10 correspond to the ten resources classified by the role
AI played in their production (see article, Section III-E). Q08_11 is
a specific item not included in the ten-resource ranking. Q10 is the
block's global rating. Q09 presents the same ten resources as
Q08_01–Q08_10, in a different order, as a forced-choice preference
item.

| Item | Label | Statement |
|---|---|---|
| Q08_01 | Interactive book | Using the interactive book (HTML/IPYNB/PDF) with integrated simulators and theory contributed significantly to my learning. |
| Q08_02 | AI-generated instructional material | The short videos (~7 min) and slides (~12 slides) produced by AI helped introduce and summarise the content before the practical class. |
| Q08_03 | Interactive simulators | Real-time visual manipulation of parameters in the interactive simulators facilitated understanding of the algorithms. |
| Q08_04 | In-class exercise resolution | Working through programming exercises together during class time was essential to my practical performance. |
| Q08_05 | `morph.py` library | Using the `morph.py` teaching library (with didactic and optimised implementations) made the algorithms' code more transparent and understandable. |
| Q08_06 | Parameterised exams/quizzes | The parameterised assessments, generated by the MCTest tool and applied via SEB (with individualised questions), were effective in fairly assessing my learning. |
| Q08_07 | Socratic feedback on the VPL | AI-generated qualitative/Socratic feedback when requesting code evaluation on VPL/Moodle exercises helped identify and correct errors in my logic. |
| Q08_08 | AI-generated rubric on quizzes/exams | The emailed report with the AI-generated detailed rubric and comparative summary added value to my review process for quizzes and exams. |
| Q08_09 | Objective VPL grading | Automatic, objective test-case validation on VPL/Moodle gave quick, clear feedback on whether my code worked. |
| Q08_10 | Use of `TestSuite.py` | `TestSuite.py` made it easier to test my exercises on Colab before submitting to the VPL. |
| Q08_11 | Network-restricted VPL *(specific item, outside the ranking)* | Being blocked from VPL access outside the university network made studying harder. |
| Q09 | Preference ranking *(forced choice, not Likert)* | Among the uses of AI in this course, choose up to 4 resources you considered most effective for your learning process. |
| Q10 | *(Block global)* | Overall, the ecosystem of methodological resources offered in this course (interactive book, AI-generated multimedia materials, simulators, teaching library, and assessments) was highly effective for my learning. |
